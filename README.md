# Code for: The bacterial march towards symbiosis: on-ramps and off-ramps
<i>Marjolein Bruijning, Andrew H. Moeller, Gavriela Carver, Mohamed S. Donia, Britt Koskella, Prerna Singh, C. Jessica E. Metcalf</i>

## Dependencies
* `R` (version 4.5.3)
* Package `fields` (version 16.3.1)
* Package `parallel` (4.5.3)
* Package `scico` (1.5.0)
* Package `popbio` (2.8)
* Package `mcprogress` (0.1.1)

## Get started
Open an R workspace and set its working directory to the folder that contains the .R files.

* `Box1.R`: code to reproduce the figures presented in Box 1.
* `Box2.R`: code to reproduce the figures presented in Box 2.
* `functions.R`: all required functions.
